# Number Guessing Game

A simple Python game where the computer generates a random number and the user tries to guess it.

## Features
- Random number generation
- User input handling
- Guess counter
- Win message

## How to Run
1. Make sure you have Python installed.
2. Open the `number_guessing_game.py` file in your editor.
3. Run the file.
4. Follow the prompts in the console to guess the number.

## Built With
- Python 3.14
